# My Journal

A personal journal application built with React and Vite.

## Features

- Create journal entries
- Add title, date, image and text
- View entries as cards
- Open an entry to see its details
- Store entries in localStorage
- Sort entries by date
- Responsive design
- Tailwind CSS styling

## Technologies

- React
- Vite
- JavaScript
- Tailwind CSS
- localStorage

## Getting Started

```bash
npm install
npm run dev
```
